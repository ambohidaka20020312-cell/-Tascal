# Tascal Chrome拡張機能

## インストール方法

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `chrome-extension` フォルダを選択
5. 拡張機能アイコンをクリックしてTascalアカウントでログイン

## 使い方

- **右クリック → Tascalにタスクとして追加** — 開いているページをタスクに追加
- **テキスト選択 → 右クリック → 「○○」をTascalに追加** — 選択テキストをタスクに追加
- **拡張機能ポップアップ** — テキスト入力でクイックタスク追加
